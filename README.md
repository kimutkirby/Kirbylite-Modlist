Kirbylite is a lightweight modlist for Skyrim Anniversarry Edition built as an “entry level modern Skyrim” focused on stability, performance, and a vanilla plus feel, powered by MCO combat and Community Shaders. It delivers smooth, animation driven combat, a subtle yet modern visual overhaul, and keeps vanilla perks and UI.

## ⚔️ MCO Based Combat
Modern, animation driven melee combat built on an MCO style framework, with responsive attacks and directional movement that still feels readable and intuitive.

## ⚔️ Vanilla Perks & Vanilla UI
Perk trees remain vanilla to keep builds simple and familiar, while the UI stays close to the original with only minimal QoL tweaks so menus and HUD are instantly recognizable.

## ⚔️ Next-Gen Look with Community Shaders
Uses Community Shaders as the core visual overhaul, bringing modern lighting, materials, and effects.
